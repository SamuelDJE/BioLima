Passos para Criar o HTML

  • Declaração DOCTYPE html: Informa ao navegador que o arquivo é HTML5.
  • Tag raiz html: Envolve todo o conteúdo da página.
  • Cabeçalho head: Onde ficam as configurações (metadados) que não aparecem no corpo da página.
  • Codificação de caracteres meta charset="UTF-8": Garante que acentos e símbolos apareçam corretamente.
  • Título title: Define o nome da página que aparece na aba do navegador.
  • Corpo body: Onde fica todo o conteúdo visível (texto, imagens, botões).
  • Títulos h1 ate h6: Hierarquia de títulos para organizar o conteúdo.
  • Parágrafos p: A tag padrão para blocos de texto.
  • Links a: Essenciais para criar a navegação entre páginas (hiperlinks).
  • Imagens img: Para incluir elementos visuais (não esqueça do atributo alt para acessibilidade).

Checklist de entrega de atividade

  • Instalar o Git: Tenha o Git configurado na sua máquina local.
  • Criar um Repositório: Crie um novo repositório no GitHub com um nome claro para a atividade.
  • Git Clone: Clone o repositório para sua máquina para trabalhar nos arquivos localmente.
  • Arquivo README.md: Crie um arquivo explicando do que se trata o projeto e como executá-lo.
  • Git Status: Verifique quais arquivos foram modificados antes de preparar o envio.
  • Git Add: Adicione os arquivos ao palco (staging area) com o comando git add ..
  • Git Commit: Escreva uma mensagem clara descrevendo o que foi feito (ex: git commit -m "Finalizando exercício de HTML").
  • Git Push: Envie suas alterações locais para o servidor do GitHub.
  • Configurar Visibilidade: Garanta que o repositório esteja como "Public" para que quem vai avaliar consiga acessar.
  • URL de Entrega: Copie o link do repositório ou da GitHub Page e cole na plataforma de entrega da sua atividade.
